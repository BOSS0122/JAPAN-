# 01 日本国憲法 — ゲームの「物理法則」

憲法は1947年施行、**一度も改正されていない**。ゲーム内でも最も変えにくいルールとして扱い、
終盤の大目標の一つを「憲法改正」に置ける。

## 三大原則

1. **国民主権** — 権力の源は国民。ゲームでは「民意（支持率・票）」がすべての力の源泉。
2. **基本的人権の尊重** — 権力が侵してはいけない領域。人権を踏みにじる政策は違憲判決・世論の反発で跳ね返る。
3. **平和主義**（第9条） — 戦争放棄・戦力不保持・交戦権否認。解釈をめぐる対立はゲーム内の最大の争点の一つ。

## 統治機構（三権分立）

```
          国会（立法）   ← 国民が選挙で選ぶ
         ／         ＼
  首相を指名        違憲立法審査
  内閣不信任        ／
       ↓          ↓
  内閣（行政） ── 最高裁判所長官を指名、裁判官を任命 → 裁判所（司法）
       ↑
  衆議院を解散（7条・69条）
```

## 主要条文とゲームへの意味

### 天皇（1〜8条）
| 条 | 内容 | ゲームへの意味 |
|---|---|---|
| 1 | 天皇は象徴。地位は国民の総意に基づく | 政治的権能なし。政治キャラとしては登場させない |
| 3・4 | 国事行為は内閣の助言と承認による。国政に関する権能はない | |
| 7 | 国事行為：法律の公布、国会召集、**衆議院の解散**、総選挙の公示など | 「7条解散」＝首相がいつでも解散できる根拠（慣行） |

### 国会（41〜64条）
| 条 | 内容 | ゲームへの意味 |
|---|---|---|
| 41 | 国会は国権の最高機関、唯一の立法機関 | 法律を作れるのは国会だけ |
| 43 | 議員は全国民の代表 | 建前。実際は地元・業界の代表として動くジレンマ |
| 45 | 衆議院の任期4年（解散あり） | 実際の平均在任は約2.5〜3年 |
| 46 | 参議院の任期6年、3年ごとに半数改選 | 参院は解散なし。安定だが首相にはなりにくい |
| 49 | 歳費を受ける | |
| 50 | **不逮捕特権**（会期中は議院の許諾なしに逮捕されない） | 逮捕許諾請求イベント |
| 51 | **免責特権**（院内の発言・表決は院外で責任を問われない） | 国会での暴露質問 |
| 52〜54 | 常会・臨時会・特別会。解散後40日以内に総選挙、選挙後30日以内に特別会 | ゲームカレンダーの基礎 |
| 53 | いずれかの議院の総議員の**1/4以上**の要求で、内閣は臨時会の召集を決定しなければならない | 野党の武器（ただし期限の定めがなく、放置が問題になる） |
| 56 | 定足数は総議員の1/3、議決は出席議員の過半数 | |
| 58 | 議員の除名は出席議員の2/3 | |
| 59 | 衆院可決・参院否決の法案は、衆院で**出席議員の2/3**で再可決すれば成立。参院が60日議決しなければ否決とみなせる | 「ねじれ国会」攻略の鍵 |
| 60 | 予算は衆院先議。参院が30日以内に議決しなければ衆院の議決が国会の議決（**自然成立**） | |
| 61 | 条約の承認も予算と同じ | |
| 62 | **国政調査権**（証人喚問など） | 野党プレイ・スキャンダル追及の武器 |
| 64 | 弾劾裁判所（裁判官を裁く） | |

### 内閣（65〜75条）
| 条 | 内容 | ゲームへの意味 |
|---|---|---|
| 66 | 首相と国務大臣は**文民**。内閣は国会に連帯して責任を負う | 閣僚の失言は内閣全体のダメージ |
| 67 | 首相は**国会議員の中から**国会が指名。衆参で異なれば両院協議会、それでも不一致なら**衆院の指名**が優先（10日ルール） | 首相になる＝衆院の多数派を握ること |
| 68 | 国務大臣は首相が任命・罷免。**過半数は国会議員** | 民間人大臣も可能。組閣はプレイヤーの重要イベント |
| 69 | 衆院で**内閣不信任案可決**（または信任案否決）→ 10日以内に衆院解散しなければ総辞職 | |
| 70 | 総選挙後に初めて国会が召集されたとき、内閣は総辞職 | |
| 73 | 内閣の仕事：法律の執行、外交、**条約の締結**、予算作成、**政令**制定、恩赦 | |
| 75 | 国務大臣は在任中、首相の同意がなければ訴追されない | |

### 司法（76〜82条）
- 76条：司法権の独立。特別裁判所の禁止。
- 79条：最高裁裁判官は**国民審査**を受ける（罷免された例はない）。
- 81条：**違憲審査権**。最高裁は「憲法の番人」。ゲームでは、無茶な法律は数年後に違憲判決で無効化されるリスクとして扱う（例：一票の格差訴訟）。

### 財政（83〜91条）
- 83条：財政は国会の議決に基づく（財政民主主義）。
- 84条：**租税法律主義** — 税は法律でしか決められない。
- 87条：予備費。
- 89条：公金を宗教団体や、公の支配に属しない慈善・教育事業に支出してはならない。
- 90条：会計検査院が決算を検査。

### 地方自治（92〜95条）
- 92条：「地方自治の本旨」（住民自治・団体自治）。
- 93条：首長と議員は住民が**直接選挙**（二元代表制）。
- 95条：特定の自治体だけに適用される特別法には、その住民投票で過半数の同意が必要。

### 改正・最高法規（96〜99条）
- 96条：改正は各議院の**総議員の2/3以上**で発議 → **国民投票で過半数**の賛成。
  国民投票の手続は「憲法改正国民投票法」（2007年制定、投票年齢18歳）。
- 98条：憲法に反する法律・命令は無効。
- 99条：天皇・大臣・議員・裁判官・公務員には**憲法尊重擁護義務**（国民には課されていない点が重要）。

## 「解釈」というもう一つのルール
条文を変えずに**政府解釈**を変えることで実質的に運用を変える手法がある
（例：集団的自衛権の限定行使を容認した2014年の閣議決定）。
政府の憲法解釈は**内閣法制局**が担ってきた。
→ ゲームでは「憲法改正ルート（正攻法・高難度）」と「解釈変更ルート（速いが反発・違憲訴訟リスク）」を選べるようにする。

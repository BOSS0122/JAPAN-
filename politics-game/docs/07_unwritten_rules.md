# 07 暗黙のルールと裏の政治

> 法律には書いていないが、永田町はこれで動いている。ゲームの「裏の教科書」。
> プレイヤーは最初これを知らず、失敗しながら（あるいは先輩に耳打ちされて）覚えていく。

## 出世の不文律
| ルール | 内容 | ゲームでの効果 |
|---|---|---|
| **当選回数主義** | 衆院で当選5〜6回あたりが初入閣の目安。「入閣待機組」が渋滞する | 能力があっても回数が足りないと大臣になれない |
| **陣笠** | 当選1〜2回の議員。採決要員として扱われる | 序盤の国政は「数のうちの1」から |
| **魔の○回生** | 大量当選した期の若手が不祥事を連発し、こう呼ばれる | 同期の不祥事が自分の評判にも影響 |
| **身体検査** | 入閣前に、スキャンダルの種がないか党・官邸が調べる | 裏金・女性問題などの「隠しフラグ」が入閣を阻む |
| **適材適所** | 組閣のたびに使われる決まり文句。実態は派閥・グループのバランスと論功行賞 | |
| **世襲** | 親の地盤・看板・カバンを継ぐ。与党衆院議員の約3割が世襲とされる（※概数） | 世襲スタートは楽だが「苦労知らず」の評判リスク |

## 根回しと国対
- **根回し**：会議で決める前に、全員の了解を個別に取っておく。会議の場で初めて反対すると「顔をつぶした」ことになる。
- **貸し借り**：「あのとき助けた」は永田町の通貨。ゲーム内に「貸し借り台帳」を持たせる。
- **国対で握る**：与野党の国対委員長が裏で日程を合意する。表の対立はある種の演出。
- **吊るし**：嫌な法案は委員会に付託させない。
- 会期末の**内閣不信任案**は、通らないと分かっていても出す恒例行事。

## 解散の不文律
- 「**解散と公定歩合は嘘をついてもいい**」：首相は直前まで「解散は考えていない」と言う。
- 解散は首相の専権。**支持率が高いうちに**、野党の準備が整う前に打つのが鉄則。
- 「**伝家の宝刀**」：抜くぞと見せるだけで党内の反乱や野党を牽制できる。

## 支持率の経験則
- 内閣支持率**30%割れ**は「危険水域」、**20%割れ**は「退陣水域」と言われる。
- 「**青木の法則**」：内閣支持率＋与党第一党の政党支持率が**50を下回る**と政権は持たない、という経験則。
- 不支持の理由が「人柄が信頼できない」になったら致命傷。
→ ゲームの政権運営パートの判定式にそのまま使える。

## 地元活動の不文律
- **金帰火来**：金曜に地元へ帰り、火曜に東京へ戻る。週末は地元行事を回る。
- **冠婚葬祭**：葬儀への参列は最重要。ただし香典は本人が出席して手渡す場合のみ（公選法）。
- **後援会**：総会、旅行、新年会。後援会の会長・幹部は地元の有力者。
- **陳情**と**箇所付け**：地元に道路・橋・補助金を持ってくると票になる（利益誘導政治）。
- **辻立ち**：駅前での朝の演説。地道だが知名度の基礎。

## スキャンダル対応の型（いわゆる「永田町話法」）
| 決まり文句 | 意味 |
|---|---|
| 「記憶にございません」 | 否定も肯定もしない。証人喚問で偽証罪を避ける |
| 「秘書がやったこと」 | 責任を秘書に転嫁。連座制や確認書制度でだんだん通用しにくくなっている |
| 「誤解を招いたとすれば遺憾」 | 発言内容ではなく「受け止め方」を問題にする |
| 「適切に対処してまいります」 | 何もしない可能性を含む |
| 「法令にのっとり適正に処理」 | 合法か違法かには触れない |
| 「職責を全うしたい」 | 辞めない。数日後に辞めることも多い |

- **辞任ドミノ**：閣僚の不祥事が続くと政権全体の支持率が急落。
- **禊（みそぎ）**：スキャンダル後に選挙で当選すれば「民意で許された」とする論理。
- **雲隠れ**：「体調不良で入院」して追及をかわす。

## メディアとの関係
- **記者クラブ**：官邸・各省・政党に記者が常駐。会見の主導権は役所と記者側に。
- **番記者**：特定の政治家に張り付く記者。「**夜討ち朝駆け**」「**夜回り**」で本音を探る。
- **オフレコ懇談**：書かない約束で話す。しかし失言がオフレコ破りで報じられることも。
- **観測気球**：わざとリークして世論の反応を見る。
- **週刊誌**：スキャンダル発掘の最大の発信源。
- **SNS**：直接発信できるが炎上リスク。切り取り動画が拡散。

## 力の源泉（ゲーム内の隠しパラメータの元ネタ）
「**数は力、力は金**」— 政治は数（議員・票）で決まり、数を集めるには金がいる。
これが裏金を生む構造でもあり、ゲームの善悪ジレンマの核心になる。

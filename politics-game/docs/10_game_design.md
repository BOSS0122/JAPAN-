# 10 ゲームデザイン案

## コンセプト
- **「政治を知らない国民」が「永田町の住人」になるまでの育成シミュレーション。**
- 表のルール（憲法・法律）と裏のルール（不文律・カネ・人間関係）の**二層構造**を体験する。
- 善悪は二択ではなく、**理想と現実のトレードオフ**の積み重ね。
  「清廉だが何も実現できない政治家」も「汚いが国を動かした政治家」もありうる。

## 学びの設計（序盤の最重要テーマ）

### 原則
1. **説明より体験**：ルールを読ませる前に、まず選ばせる。失敗したら理由を教える。
2. **表と裏を並べて見せる**：同じ出来事に「教科書の説明（表）」と「先輩の耳打ち（裏）」の2つの解説を出す。
3. **ゲームオーバーにしない**：序盤のルール違反は「注意」「始末書」程度で済み、学びに変わる。
   中盤以降は本物の結果（失職・逮捕）になる。
4. **出典を示す**：重要な判定では「公職選挙法 第199条の2」のように根拠条文を表示し、本物の知識として持ち帰れるようにする。

### 学習システム
| 仕組み | 内容 |
|---|---|
| **メンター** | ベテラン秘書（架空キャラ）。プレイヤーが迷うと耳打ちしてくれる。表の顔は真面目、裏の事情にも通じている |
| **永田町手帳** | 用語を体験するたびに解放される図鑑。[11_glossary](11_glossary.md) が元データ。表の意味／裏の意味の2段構成 |
| **合法？グレー？違法？** | 判断クイズを「イベントの選択肢」として埋め込む。正解率が「コンプラ力」パラメータに反映 |
| **振り返り** | 章の終わりに「今回あなたが触れたルール」を一覧表示 |
| **ニュース画面** | ゲーム内ニュースで、他の架空政治家の不祥事・法改正が流れる。世の中の動きとルールの関係を学ぶ |

## 基本の遊び方：物語とシミュレーションの組み合わせ

物語の場面（テキストアドベンチャー）と、数値を育てる期間（シミュレーション）が交互に来る。

```
[物語] 場面を読み、選択肢を選ぶ ─ 合法・グレー・違法の判定、表と裏の解説
   ↓  選んだ結果が数値に反映される
[月を過ごす] 限られた行動回数で活動を選ぶ ─ 信頼・人脈・資金・知識を育てる
   ↓  期間の終わりに、数値に応じた出来事（週刊誌の取材、支援者の紹介など）が起きる
[物語] 次の場面。数値が足りないと、正しい選択をしても失敗することがある
   ↓  …を繰り返して
[選挙] それまでの数値と選挙運動から得票を計算し、当落が決まる
```

数値と物語のつながり：
- **判定（check）**：先生を止める、口利きを断る、裏金を正すといった選択は、人脈や信頼が足りないと失敗する。
  「正しいことを言っても、聞いてもらえる関係がなければ通らない」という政治の現実を表す。
- **法律知識**：一定以上になると、選択肢に「違法のおそれ」「グレーゾーン」の注意が見えるようになる。
  勉強に行動を使うほど、裏の罠を見抜けるようになる。正しい判断をしても知識が増える。
- **資金**：行動にはお金がかかるものがあり、足りなければ選べない（議員会館への出張、選挙カーなど）。
- **発覚リスク**：裏の行動や違法な選択で溜まり、毎月の終わりに確率で表に出る。
  選挙で高すぎれば得票が削られ、当選しても後で捕まる。
- **得票の内訳**を開票画面で見せ、何が勝因・敗因だったかを振り返れるようにする。

- **舞台が広がると数値が薄まる**：市議から衆院選に進むと、選挙区の有権者は5倍になる。
  章の始まりに信頼と人脈を割り引き、「市での人気は国政では通用しない」ことを表す。
- **時間が経つと発覚リスクは減る**（時効。不記載は5年、買収は3年）。ただしゼロにはならない。
- **摘発は確率**：発覚リスク70を超えると当選後に摘発されることがあり、100なら必ず摘発される。
- **落選しても終わらない**：その章のはじめからやり直せる。行動の選び方を変えて再挑戦する。

試作版での手応え（自動プレイでの確認、序章〜第4章）：
| 遊び方 | 結果 |
|---|---|
| 正しい判断を重ね、信頼重視 | 市議は上位当選。国政は公認争いに負けて無所属になりがちで、小選挙区は五分五分 |
| 正しい判断を重ね、人脈重視 | 公認を取り、国政も当選 |
| 黙認ルート（裏金を見逃す）＋選挙前の現金配布 | 国政まで進むが、当選後に逮捕 |
| 裏の手段をすべて使う | 市議選で当選後に摘発 |
| 勉強だけで人とつながらない | 市議選で落選 |

## プレイヤーのパラメータ
| 区分 | パラメータ | 意味 |
|---|---|---|
| 能力 | 弁舌 / 政策力 / 交渉力 / 体力 | 演説・質問・根回し・地元回りの成功率 |
| 外向け | **知名度** / **支持率**（選挙区） / イメージ（清廉↔黒い） | 選挙の勝敗 |
| 資源 | **資金** / 後援会（地盤） / 秘書・スタッフ | 活動量の上限 |
| 永田町 | **党内影響力** / グループ所属 / 当選回数 / 役職 | 出世・ポスト |
| 関係 | 官僚 / 業界団体 / 労組・宗教団体 / メディア / 地方議員 / 他党 | それぞれ好感度。高すぎると「取り込まれる」 |
| 裏 | **貸し借り台帳** / **発覚リスク** / 恨み（NPCごと） / 弱み（握った・握られた） | 裏の政治の核 |
| 内面 | **信念ゲージ** | 理想をどれだけ保っているか。妥協するほど減り、エンディングに影響 |

## キャリアと章構成
| 章 | 立場 | 学ぶこと | 主なイベント |
|---|---|---|---|
| 序章 | 一般市民（18歳〜） | 選挙権、投票の仕組み、三権分立 | 初めての投票。地元の道路計画に疑問を持つ |
| 第1章 | 議員事務所のボランティア → 秘書 | 公職選挙法（寄附禁止・戸別訪問・事前運動）、後援会、冠婚葬祭、政治資金の帳簿 | 「この差し入れは渡していい？」クイズ。帳簿の数字が合わないことに気づく（最初の裏の入口） |
| 第2章 | 市議選に出馬 | 供託金、選挙運動期間、ポスター、ネット選挙、組織票 | 公認・推薦をもらうか無所属か。資金集め |
| 第3章 | 市議会議員 | 二元代表制、予算審議、一般質問、会派、百条委員会、直接請求 | 市長の不正疑惑。業者からの接待の誘い |
| 第4章 | 県議 or 国政へ挑戦 | 小選挙区と比例、惜敗率、公認争い、コスタリカ方式 | 現職との公認争い。世襲候補とのライバル関係 |
| 第5章 | 衆議院1年生（陣笠） | 国会の会期・委員会・党議拘束・部会・国対・パーティー券 | **最初の大きな選択：派閥（グループ）のパーティー券ノルマとキックバック** |
| 第6章 | 中堅（政務官・副大臣・党役職） | 官僚との関係、予算編成、族議員、陳情 | 業界団体の支援と引き換えの政策要求 |
| 第7章 | 大臣 | 閣議、国会答弁、身体検査、失言、辞任ドミノ | 予算委員会での追及。答弁を官僚に頼るか自分の言葉で話すか |
| 第8章 | 総裁選 → 総理 | 推薦人20人、多数派工作、組閣、解散権、連立 | 解散のタイミング判断、支持率と青木の法則 |
| 終章 | 総理として | 憲法改正（発議・国民投票）、外交、歴史の評価 | エンディング分岐 |

野党ルート（野党議員として政権交代を目指す）、地方ルート（知事・市長を極める）も分岐として用意したい。

## 善悪システム
### 3つの軸（二元論にしない）
1. **清廉度**：法とルールを守ったか（合法 ←→ 違法）
2. **実行力**：何を実現したか（政策の成果）
3. **民意**：国民のためになったか（短期の人気ではなく長期の評価）

### ジレンマの例
| 場面 | 清廉な選択 | 現実的な選択 | 黒い選択 |
|---|---|---|---|
| パーティー券のノルマ超過分 | 全額を正しく記載 | 派閥に返す（グループ内で浮く） | キックバックを受け取り不記載 |
| 業界団体からの支援 | 断る（組織票を失う） | 政策が一致する範囲で受ける | 見返りに口利きを約束 |
| 大臣の失言をかばうか | 辞任を進言 | 様子見 | 記者に別スキャンダルをリークして話題をそらす |
| 地元への公共事業 | 必要性を精査 | 地元の要望どおり要求 | 特定業者に落札させて献金を受ける |
| 解散時期 | 公約通り任期満了 | 支持率が高いうちに解散 | 不祥事隠しのために解散 |

### 発覚システム
- 黒い選択をするたびに**発覚リスク**が上がり、関わったNPCに「弱み」を握られる。
- 毎ターン、リスク値・敵対NPCの恨み・メディア関係から発覚判定。
- 発覚の経路：収支報告書の突き合わせ（市民団体）、週刊誌、元秘書の告発、ライバルのリーク、特捜部。
- 結末：謝罪で済む → 離党 → 議員辞職 → 逮捕 → 有罪・公民権停止。「禊選挙」で復活ルートもある。

### エンディング例
- **国士**：清廉かつ実行力も高い（最難関）。
- **改革者の挫折**：清廉だが何も実現できずに落選。
- **ドン**：裏の力で長く権力を握り続ける。歴史の評価は辛い。
- **獄中の元総理**：頂点に立ったが、最後に過去が露見。
- **現実主義者**：グレーを渡り切り、成果を残した。評価は分かれる。

## 時間とターン
- 1ターン＝1か月を基本。国会カレンダー（1月常会召集、150日会期、夏の参院選、秋の臨時国会、12月予算編成）に沿って進む。
- 選挙はカレンダーで固定（参院は3年ごと、地方は統一地方選など）＋解散によるランダム性。

## 表現上の方針
- 人物・政党・団体はすべて**架空**。実在の事件は構造のみ参考にする。
- 特定のイデオロギーを正解にしない。政策の選択肢には左右どちらの立場も用意し、
  評価は「一貫性」「実現度」「民意との一致」で行う。
- 違法行為は抽象化した選択肢として扱い、現実の具体的手口を教える内容にはしない。
- ゲーム内に「この知識は○年○月時点の制度に基づきます」と表示し、制度変更に追従できるようデータを分離する。

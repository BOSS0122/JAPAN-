# 03 選挙制度と公職選挙法

> 「猿は木から落ちても猿だが、代議士は選挙に落ちればただの人」— 昭和の政治家の格言。
> ゲームのあらゆるパラメータは、最終的に「次の選挙で勝てるか」に収束する。

## 選挙権・被選挙権
- 選挙権：**18歳以上**（2016年から）。
- 被選挙権：衆院議員・市区町村長・地方議員 **25歳以上**、参院議員・都道府県知事 **30歳以上**。

## 衆議院：小選挙区比例代表並立制（1996年〜）
- 小選挙区289：1区から1人。**最多得票者のみ当選**。死票が多く、大政党に有利。
- 比例代表176：全国11ブロック。政党名で投票し、**ドント方式**で議席配分。拘束名簿式。
- **重複立候補**：小選挙区と比例の両方に立候補できる。同じ順位に並べた候補は**惜敗率**
  （本人の得票 ÷ その区の当選者の得票）が高い順に当選＝「**比例復活**」「ゾンビ当選」。
  ただし小選挙区で有効投票の**1/10未満**だった候補は復活できない。
- 選挙運動期間：**12日間**。

## 参議院
- 選挙区148：原則都道府県単位（鳥取・島根、徳島・高知は**合区**）。1人区は事実上の小選挙区で、勝敗の鍵。
- 比例代表100：全国1ブロック。**非拘束名簿式**（候補者名でも政党名でも投票可。個人名票の多い順に当選）。
  **特定枠**（2019年〜）を使えば政党が優先当選者を指定できる。
  → 業界団体・労働組合・宗教団体などの**組織票**を持つ「組織内候補」が強い。
- 3年ごとに半数改選（124議席）。選挙運動期間：**17日間**。

## 一票の格差
選挙区ごとに有権者数が違うため、一票の重みに差が出る。最高裁はたびたび「違憲状態」と判断。
→ 区割り変更（衆院の「10増10減」など）はベテラン議員の地盤を消すため、党内で激しく揉める。

## 公職選挙法：やってはいけないこと（序盤クイズの宝庫）
| 禁止事項 | 内容 | ゲーム内の例 |
|---|---|---|
| **事前運動の禁止** | 公示・告示前の「投票してください」は違法 | ただし「政治活動」（政策の訴え、後援会活動）は可。境界がグレー |
| **戸別訪問の禁止** | 投票依頼のために家を一軒ずつ回るのは禁止 | 日本独特。海外では普通の選挙活動 |
| **寄附の禁止** | 候補者・議員（なろうとする者を含む）は選挙区内の人へ**時期を問わず**寄附禁止 | お中元、お歳暮、花輪、うちわ配布（法相が辞任した例あり）、果物などの贈答品 |
| 香典・祝儀 | 原則禁止。**本人が自ら出席して渡す**場合のみ罰則の対象外 | 秘書の代理参列で香典を渡すとアウト |
| **買収** | 票や運動の対価として金品を渡す | 最も重い選挙犯罪。地元首長らへの現金配布事件も |
| 運動員への報酬 | 選挙運動は原則無償ボランティア。例外はウグイス嬢など法定の範囲のみ | 日当を払うと「運動員買収」 |
| 飲食物の提供 | 湯茶と通常の茶菓子程度まで（選挙事務所の弁当にも制限） | |
| 文書図画 | ポスター・ビラは種類・枚数が法定 | |
| ネット選挙 | 2013年解禁。ウェブサイト・SNSでの運動は誰でも可。**電子メール**での運動は候補者・政党のみ。18歳未満は選挙運動禁止 | |

## 連座制
秘書・出納責任者・親族・**組織的選挙運動管理者**などが買収等で有罪になると、
**候補者本人の当選が無効**になり、**同じ選挙区から5年間立候補できない**。
→ 「秘書がやったこと」でも本人が失職しうる。ゲームでは秘書の忠誠度・コンプラ意識が重要パラメータ。

## 選挙の勝ち方（実態）
- **地盤**（後援会・組織）・**看板**（知名度）・**カバン**（資金）の「三バン」。
- 「**風**」（党首人気・ブーム）と「**組織**」（業界団体・労組・宗教団体・後援会）。
- 「選挙区を歩いた靴の数だけ票が出る」：辻立ち、ミニ集会、祭り・運動会・葬儀への顔出し。
- 投票率が低いほど組織票の比重が上がる。
- 選挙費用は法定上限があるが、公示前の「政治活動」に費用がかかる構造。

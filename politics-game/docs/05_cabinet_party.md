# 05 内閣・官僚・政党 — 権力はどこにあるか

## 内閣
- 総理大臣 + 国務大臣（原則14人以内、特別の必要があれば17人以内。復興など特例で増員あり）。
- 各大臣の下に**副大臣**・**大臣政務官**（政務三役）。若手〜中堅議員の登竜門。
- **閣議**：非公開、**全会一致**が慣行。反対する大臣は罷免される（反対のまま閣議決定はできない）。
- **内閣官房長官**：政府のスポークスマン（1日2回の記者会見）であり、官邸の要。
- 首相の強力な武器：
  1. **人事権**（大臣の任免、党の役職への影響力）
  2. **解散権**（7条解散＝慣行として首相の専権事項）
  3. **内閣人事局**（2014年〜）を通じた各省幹部約600人の人事への関与 → 官僚の「**忖度**」問題

## 官僚（霞が関）
- 法案・予算の原案を作るのは実質的に各省庁。
- 政治家の情報源であり、時に抵抗勢力。**根回し**（ご説明＝レク）に来る。
- 予算編成：各省が概算要求（8月末）→ 財務省主計局が査定 → 12月に政府案 → 1月国会提出 → 3月末までに成立。
  財務省は「省庁の中の省庁」。
- **天下り**：退職後に関連団体・企業へ再就職。業界・役所・族議員の三角関係（**鉄のトライアングル**）。
- 官僚との関係パラメータ：高いと政策実現力が上がるが、官僚の論理に取り込まれる（「役所の振り付け」）。

## 政党の仕組み（与党の場合をモデルに）
### 党の役職
- **総裁（党首）**：与党第一党の総裁＝ほぼ首相。
- **幹事長**：党の**カネ（党資金の配分）**と**公認（選挙の候補者決定）**を握る。実質的なナンバー2。
- **総務会長**：党の最高意思決定機関「総務会」の長。
- **政調会長**：政策の責任者。部会を束ねる。
- **選対委員長**：選挙の司令塔。
- **国対委員長**：国会運営の裏方。他党との交渉役。

### 与党事前審査制（法案は国会の前に党で決まる）
```
各省の原案 → 党の部会（○○部会：分野ごとの族議員の主戦場）
           → 政務調査会審議会
           → 総務会（全会一致が慣行）
           → 閣議決定 → 国会提出
```
- 党で了承された時点で**党議拘束**がかかる。国会審議は「通す儀式」になりがち。
- 部会で大声を出すベテラン族議員が実際の政策を動かす。若手が存在感を出す場でもある。

### 派閥・グループ
- かつての派閥の機能：**カネ**（パーティー収入の分配、選挙資金）、**ポスト**（大臣・党役職の推薦）、
  **総裁選**（数の力）、**新人教育**、選挙応援。
- 2023〜24年の資金問題を受けて多くの派閥が解散を表明。ただし政策グループや勉強会、
  人的ネットワークとしての結びつきは残る。
  → ゲームでは「派閥」を「グループ」として残し、加入・離脱・旗揚げを選べるようにする。

### 総裁選（与党第一党の例）
- 立候補には**国会議員の推薦人20人**が必要。→「20人集める」が最初の関門。
- 1回目：国会議員票＋党員・党友票（議員票と同数に換算）。過半数なしなら上位2人で決選投票（議員票＋都道府県連票）。
- 任期3年、連続3期まで（党則による）。
- 実際の勝負は告示前の「多数派工作」で決まることが多い。

### 公認
- 小選挙区では1つの党から1人しか出せない。現職優先が原則。
- 選挙区が重なった2人を交互に小選挙区と比例に回す「**コスタリカ方式**」などの調整術。
- 公認を外されると無所属で出るか、引退か、他党へ移るか。
- 比例単独候補の**定年制**（例：73歳）を設ける党もある。

## 連立
- 単独過半数がなければ他党と連立・閣外協力・政策ごとの部分連合を組む。
- 小政党は「キャスティングボート」を握り、政策要求を通す。
- 連立の組み替え・離脱はゲーム中盤〜終盤の大イベント。

## 野党の戦い方
- 国会での追及（予算委員会・質問主意書）、対案の提出、審議日程の駆け引き。
- 野党共闘・候補者一本化（小選挙区で勝つには一本化が必須）。
- 政権交代は「風」が吹いたときに起きる（ゲームでは世論ゲージ＋与党スキャンダル蓄積で発生）。

# 02 国会と立法

## 二院制
| | 衆議院 | 参議院 |
|---|---|---|
| 定数 | 465（小選挙区289・比例176） | 248（選挙区148・比例100） |
| 任期 | 4年（解散あり） | 6年（3年ごとに半数改選、解散なし） |
| 被選挙権 | 25歳以上 | 30歳以上 |
| 性格 | 「民意の鏡」。首相指名・予算で優越 | 「良識の府」「再考の府」 |

### 衆議院の優越（まとめ）
| 事項 | 参院が異なる議決をしたら | 参院が議決しなかったら |
|---|---|---|
| 法律案 | 衆院で出席議員の2/3で再可決 | 60日でみなし否決 → 再可決可 |
| 予算 | 両院協議会で不一致なら衆院の議決 | 30日で自然成立 |
| 条約承認 | 同上 | 30日で自然成立 |
| 首相指名 | 同上 | 10日で衆院の指名 |
| 内閣不信任 | 衆院のみの権限 | — |

> **ねじれ国会**：衆院与党・参院野党の状態。予算は通るが**予算関連法案（特例公債法など）**が通らず、
> 政権が行き詰まる。ゲームの難易度を一気に上げるイベント。

## 会期
| 種類 | 召集 | 会期 | 延長 |
|---|---|---|---|
| 常会（通常国会） | 毎年1月 | 150日 | 1回まで |
| 臨時会（臨時国会） | 内閣が決定（または1/4要求） | 両院一致で決める | 2回まで |
| 特別会（特別国会） | 総選挙後30日以内 | 両院一致で決める | 2回まで |
| 参議院の緊急集会 | 衆院解散中の緊急時 | — | — |

- **会期不継続の原則**（国会法68条）：会期中に議決されなかった案件は廃案。
  閉会中審査の手続をとれば継続審議にできる。
  → 野党の基本戦略は「時間切れ」に持ち込むこと。**日程こそが武器**。

## 法律ができるまで
```
[閣法]  各省で原案 → 審議会・業界調整 → 内閣法制局審査 → 与党事前審査（部会→政調→総務会）→ 閣議決定
[議員立法] 議員が起案（衆議院法制局・参議院法制局が支援）
        ↓
  提出（衆院 or 参院）
        ↓
  議院運営委員会で付託先を決める ←「吊るし」：付託されずに放置される
        ↓
  委員会審査（趣旨説明 → 質疑 → 参考人・公聴会 → 討論 → 採決）
        ↓
  本会議で採決 → もう一方の院へ（同じ流れ）
        ↓
  成立 → 天皇が公布
```
- **議員立法の提出要件**（国会法56条）：衆院は議員20人以上（予算を伴う場合50人）、
  参院は10人以上（同20人）の賛成者が必要。さらに多くの政党は**党内手続き（機関承認）**を求める。
- 成立する法案の大半は**閣法**。議員立法は数は出るが成立率は低い。
  → 一年生議員が「自分の法案」を通すのは非常に難しい、というリアリティをゲームに反映。

## 委員会中心主義
- 実質的な審議は**委員会**で行う。常任委員会は衆参それぞれ17。
- **予算委員会**：テレビ中継され、予算と関係のないテーマ（スキャンダル）も追及できる最大の見せ場。
- **議院運営委員会（議運）**：本会議の日程・議題を決める。日程を握る者が国会を握る。
- 委員長ポストは与党がほぼ独占（ねじれ時は野党も獲得）。委員長は審議日程の主導権を持つ。

## 国対政治（裏の国会運営）
- 各党の**国会対策委員会（国対）**の委員長同士が、非公式に「どの法案をいつ通すか」を交渉する。
- 典型的な取引：「この法案の採決を認める代わりに、あの法案は今国会で見送る」
  「大臣の答弁修正（謝罪）と引き換えに審議に復帰する」。
- 野党の抵抗手段：**審議拒否**、**牛歩戦術**（投票でゆっくり歩く）、委員長解任決議案、
  大臣不信任・問責決議案、**内閣不信任案**（会期末の恒例行事）。
- 与党の強行手段：**強行採決**（委員長職権で採決）。世論の反発ゲージが上がる。

## 本会議の採決方法
起立、記名投票（白票・青票）、異議なし採決、押しボタン（参院）。
党議拘束に反して造反すると、党の処分（役職停止・公認取り消し・除名）を受ける。

## 国政調査権の道具
| 手段 | 内容 |
|---|---|
| 証人喚問 | 議院証言法に基づく。**虚偽の証言は偽証罪**。出頭・証言拒否にも罰則。全会一致の慣行があり与党が渋る |
| 参考人招致 | 任意。嘘をついても罰則なし |
| 政倫審（政治倫理審査会） | 議員の政治倫理を審査。原則非公開、本人申し出も可 |
| 質問主意書 | 文書で内閣に質問し、閣議決定された答弁書が返ってくる。少数会派の武器 |

# 06 地方自治 — 序盤の舞台

国会議員の多くが**地方議員・秘書・首長**からキャリアを始める。ゲーム序盤は市議会を舞台にする。

## 二元代表制
- 首長（知事・市町村長）と議員を、住民が**それぞれ直接選挙**で選ぶ（憲法93条）。
- 国の議院内閣制と違い、首長と議会は対等で独立。首長が予算案・条例案の大半を出し、議会が審議する。
- 実態：多くの議会は首長を支える「オール与党」状態。議員は「質問」と「予算要望（地元への箇所付け）」が主な活動。

## 首長と議会の対立ルール（地方自治法）
| 仕組み | 内容 |
|---|---|
| 不信任議決 | 議員数の2/3以上が出席し、その3/4以上の同意で首長を不信任 → 首長は10日以内に議会を解散できる。解散後の初議会で再び不信任（2/3出席・過半数同意）されれば首長は失職 |
| 再議（首長の拒否権） | 議会の議決に異議があれば差し戻せる。条例・予算は出席議員の2/3で再可決すれば確定 |
| 専決処分 | 議会を招集する暇がない場合などに首長が代わりに決める。乱用は問題に |
| 百条委員会 | 地方自治法100条に基づく調査。証人喚問・偽証罪あり。首長のスキャンダル追及の場 |

## 住民の直接請求
| 請求 | 必要署名 | 請求先 |
|---|---|---|
| 条例の制定・改廃 | 有権者の1/50以上 | 首長 |
| 事務の監査 | 1/50以上 | 監査委員 |
| 議会の解散 | 1/3以上（大都市は緩和） | 選挙管理委員会 → 住民投票 |
| 首長・議員の解職（リコール） | 1/3以上（同上） | 選挙管理委員会 → 住民投票 |

→ 序盤の「市民ルート」で、署名運動から政治に関わるイベントが作れる。

## 地方政治のリアル
- 議員報酬は自治体規模で大きく違う（町村議は月20万円前後、政令市議は月80万円前後など。※概数）。
  なり手不足の町村では無投票当選も多い。
- 地方議員は国会議員の**集票マシン**（「系列」）。国政選挙で地元を回る代わりに、県議選で応援してもらう。
- 地方交付税・補助金をめぐる国への陳情。国会議員とのパイプが首長の力になる。
- 首長から国政へ、国政から知事へ転じるルートもある。

# 04 政治とカネ — 表の財布と裏の財布

## 政治資金規正法の基本
- **政治団体**を作って政治資金を出し入れし、毎年**収支報告書**を提出・公開する（「ガラス張り」が建前）。
- 政治家ごとに**資金管理団体**を1つ指定できる。他にも政党支部・後援会など複数の団体を持つのが普通。
- **企業・団体献金**は、**政党・政治資金団体**に対してのみ可（政治家個人・資金管理団体へは不可）。
  → 抜け道として、政治家が支部長を務める**政党支部**が受け皿になってきた。
- **個人献金**の上限：政党等へ年2,000万円、それ以外の政治団体・候補者へ年1,000万円の総枠。同一の政治団体へは年150万円まで。
- **パーティー券**：1回のパーティーで同一人物からの購入は150万円まで。
  購入者名の公開基準は**20万円超**だったが、2024年改正で**5万円超**に引き下げ（施行は2027年〜、※要確認）。
- 寄附者の公開基準：年**5万円超**。
- 寄附の禁止：国から補助金を受けている企業、赤字企業、外国人・外国法人（一部例外あり）など。
- 罰則：**不記載・虚偽記入**は5年以下の拘禁刑または100万円以下の罰金（刑法改正で2025年から懲役・禁錮→拘禁刑）。

### 近年の改正（2024年）
- 2023〜24年に**派閥の政治資金パーティー収入の還流・不記載（いわゆる裏金問題）**が発覚し、議員・会計責任者が立件、多数の派閥が解散。
- 2024年6月改正：議員本人に収支報告書の**確認書**作成を義務化（確認を怠り会計責任者が処罰された場合、議員本人にも罰則・公民権停止がありうる）、パーティー券公開基準の引下げ、収支報告のオンライン化など。
- 2024年12月改正：使途を明かさずに党から幹部へ渡せた「**政策活動費**」を廃止。監視のための第三者機関設置へ。
- **企業・団体献金の禁止・規制強化**は継続的な政治争点。

## 政党助成制度（政党交付金）
- 政党助成法（1995年〜）。国民1人あたり250円 × 人口 ＝ 年**約315億円**を各党に配分。
- 交付要件（政党要件）：国会議員**5人以上**、または国会議員1人以上かつ直近の国政選挙で得票率**2%以上**。
- 議員数割と得票数割で配分。受け取らない方針の政党もある。
- 使い道は報告義務あり。余れば基金として積み立てられる。
→ 新党結成イベントで「5人集めれば交付金が出る」という生々しい計算を体験させる。

## 裏金・グレーな資金の典型構造（ゲーム用に抽象化）
| 類型 | 構造 | 合法性 | ゲーム内のバレ方 |
|---|---|---|---|
| パーティー券キックバック | 派閥の販売ノルマ超過分を議員に戻し、どちらの報告書にも載せない | **違法（不記載）** | 研究者・市民団体の報告書突き合わせ → 告発 → 特捜部 |
| 迂回献金 | 献金を政党支部や別団体を経由させ、出所をわかりにくくする | グレー〜違法 | 記者の調査報道 |
| 分散購入 | パーティー券を複数名義に分けて公開基準以下にする | グレー | 内部告発 |
| 事務所費・人件費の水増し | 実態のない支出の計上 | 違法 | 元秘書の告発、週刊誌 |
| 秘書給与の流用 | 公設秘書の給与を事務所に「寄附」させる | 違法（詐欺等） | 元秘書の告発 |
| 口利き・あっせん | 公共事業・許認可で業者に便宜を図り見返りを受ける | **あっせん利得罪・収賄** | 談合発覚・業者の供述 |
| 選挙買収 | 地方議員・首長に現金を配る | **公選法違反（買収）** | 受け取った側の自白 |
| 使途不明の党資金 | 党本部から幹部個人へ（旧・政策活動費） | 2024年改正で廃止 | ― |

## 摘発する側（ゲームの「敵」・リスク要因）
- **東京地検特捜部**：大型の政治資金・汚職事件を独自捜査。国会会期中は不逮捕特権の壁（逮捕許諾請求）。
- **警察（捜査二課）**：選挙違反。
- **国税**：申告漏れ。
- **週刊誌・新聞の調査報道**、**市民団体・研究者**による告発。
- **内部告発者**：冷遇された元秘書、裏切られた業者、派閥抗争の相手。
  → ゲームでは「恨みを買ったNPC」が時限爆弾になる仕組みが面白い。

## ゲームでの扱い（方針）
- 裏金は「資金ゲージが一気に増える」が、**発覚リスク値**が溜まり、毎ターン判定される。
- 発覚時の結末：離党・議員辞職・逮捕・有罪で公民権停止、あるいは「禊選挙」での復活。
- 清廉ルートは資金不足だが、「信頼」「クリーンなイメージ」で終盤に強くなる。
- 「グレー」の選択肢を多く用意し、**合法・グレー・違法の判断力そのもの**を育てる学習要素にする。

# 11 用語集（「永田町手帳」の元データ）

各用語は **表**（教科書的な意味）と **裏**（現場での実態・先輩の耳打ち）の2段で記述。
「解放章」はゲーム内で初めて出会う章の目安。

| 用語 | 表 | 裏 | 解放章 |
|---|---|---|---|
| 三権分立 | 立法・行政・司法を分け、互いに抑制させる仕組み | 実際は与党が国会と内閣の両方を握るので、立法と行政の境目は薄い | 序章 |
| 選挙権 | 18歳以上の国民が持つ投票する権利 | 若者の投票率は低く、政治家は投票に来る高齢層を向きがち | 序章 |
| 陳情 | 行政・議会・議員に要望を伝えること。請願と違い議員の紹介は不要 | 国会議員の地元事務所の仕事の多くは陳情の受付。叶えれば票になる | 序章 |
| 辻立ち | 駅前や交差点に立って行う演説 | 毎朝立つ姿そのものが知名度と信頼になる | 1 |
| 口利き | 政治家が役所などに働きかけること | 報酬を受け取ればあっせん利得罪。支援者の頼みは断りにくい | 1 |
| 裏金 | 収支報告書に載せず、出入りが見えなくなったお金 | 使い道を問われないお金は、選挙と人間関係に流れていく | 1 |
| 後援会 | 政治家を支援する人々の団体 | 地盤そのもの。親から子へ「相続」される | 1 |
| 寄附禁止 | 候補者等は選挙区内の人に寄附してはいけない（公選法199条の2） | お中元、花輪、うちわ一本でも大問題になりうる | 1 |
| 戸別訪問 | 投票依頼のための家庭訪問は禁止（公選法138条） | 「ご挨拶回り」と称する活動との境界はグレー | 1 |
| 事前運動 | 公示・告示前の選挙運動は禁止 | 「政治活動」なら可。二連ポスターや後援会入会の呼びかけで実質的に運動する | 1 |
| 収支報告書 | 政治団体が毎年提出・公開する会計報告 | 書かなければ見えない。不記載が裏金の正体 | 1 |
| 冠婚葬祭 | 地元の結婚式・葬儀などへの参列 | 票につながる最重要業務。香典は本人が出席して渡す場合のみ罰則対象外 | 1 |
| 供託金 | 立候補時に預けるお金。得票が少ないと没収 | 新人にとって最初の壁 | 2 |
| 組織票 | 業界団体・労組・宗教団体などがまとめて投じる票 | 投票率が低いほど威力を増す | 2 |
| 二元代表制 | 首長と議会をそれぞれ住民が直接選ぶ仕組み | 実際は議会の多くが首長を支える「オール与党」 | 3 |
| 会派 | 議会の中で行動を共にする議員のグループ | ポストも質問時間も会派で決まる。大きな会派ほど首長に逆らいにくい | 3 |
| 政務活動費 | 議員の調査研究のため、条例にもとづいて交付されるお金 | 領収書の偽装で辞職が相次いだ。住民監査請求は1人でもできる | 3 |
| 系列 | 国会議員を頂点に県議・市議がつながる関係 | 地方議員は国政選挙の集票役。お金が絡めば買収 | 4 |
| 世襲 | 親族の地盤を受け継いで立候補すること | 地盤・看板・カバンを丸ごと相続できる | 4 |
| 一般質問 | 議員が首長に市政全般について質問すること | 質問は事前に通告され、答弁は職員が書く。「台本どおり」の議会 | 3 |
| 百条委員会 | 地方議会の強い調査権を持つ特別委員会 | 首長スキャンダルの最終兵器 | 3 |
| 小選挙区 | 1選挙区から1人が当選する制度 | 1位以外は全部死票。党の公認がほぼ必須 | 4 |
| 惜敗率 | 小選挙区の当選者の得票に対する自分の得票の割合 | 比例復活の命綱。「ゾンビ当選」と揶揄される | 4 |
| 公認 | 政党が正式な候補者として認めること | 幹事長が握る最強のカード | 4 |
| 三バン | 地盤・看板・カバン | 世襲が強い理由そのもの | 4 |
| 会期不継続 | 会期中に議決されなかった法案は廃案になる原則 | 野党は時間切れを狙う。日程こそ武器 | 5 |
| 党議拘束 | 党の決定どおりに投票させること | 造反すれば役職停止・公認剥奪 | 5 |
| 部会 | 与党の政策分野ごとの会議 | 族議員の主戦場。法案の中身は実質ここで決まる | 5 |
| 国対 | 国会対策委員会。国会運営を担う | 与野党の国対委員長が裏で日程を「握る」 | 5 |
| 吊るし | 法案を委員会に付託せず放置すること | 嫌な法案を葬る静かな手段 | 5 |
| 陣笠 | 当選回数の少ない平議員 | 採決要員。発言力はほぼない | 5 |
| 政治資金パーティー | 券を売って政治資金を集める会 | 主要財源。ノルマとキックバックが裏金を生んだ | 5 |
| 派閥 | 党内の議員集団 | カネ・ポスト・総裁選の数。解散しても人間関係は残る | 5 |
| 族議員 | 特定の政策分野・業界に強い議員 | 業界・官僚・議員の「鉄のトライアングル」 | 6 |
| 箇所付け | 予算をどの地域・事業に配分するか | 地元に持ち帰れば票になる | 6 |
| レク | 官僚による政治家への説明 | 官僚の「振り付け」の入口 | 6 |
| 天下り | 退職官僚が関連団体・企業に再就職すること | 規制されても形を変えて続く | 6 |
| 身体検査 | 入閣前のスキャンダル調査 | 隠しフラグはここで効いてくる | 7 |
| 証人喚問 | 国会が証人を呼び、偽証罪付きで証言させる | 「記憶にございません」の舞台 | 7 |
| 忖度 | 相手の意向を推し量って行動すること | 人事権を握られた官僚が、指示なしに動く | 7 |
| 辞任ドミノ | 閣僚の辞任が相次ぐこと | 政権の支持率を一気に削る | 7 |
| 推薦人 | 総裁選の立候補に必要な国会議員の推薦（20人） | 最初の20人を集められるかが実力の証明 | 8 |
| 解散権 | 首相が衆議院を解散する権限（7条解散） | 「嘘をついてもいい」とされる伝家の宝刀 | 8 |
| 青木の法則 | 内閣支持率＋与党第一党支持率が50を下回ると政権は持たないという経験則 | 退陣カウントダウンの目安 | 8 |
| 連立 | 複数政党で政権をつくること | 小政党がキャスティングボートを握る | 8 |
| 憲法改正 | 各院総議員2/3で発議、国民投票で過半数 | 一度も実現していない最難関の目標 | 終章 |
| 政党交付金 | 国が政党に配る政治資金（年約315億円） | 議員5人集めれば新党に交付金が出る | 随時 |
| 連座制 | 秘書等の選挙犯罪で候補者の当選が無効になる制度 | 「秘書がやった」では逃げられない | 随時 |
| 特捜部 | 検察の特別捜査部。大型の政治事件を捜査 | 永田町が最も恐れる存在 | 随時 |
| 禊 | スキャンダル後に選挙で当選し、民意で許されたとすること | 当選しても事実は消えない | 随時 |

# 政治家育成ゲーム（仮題：『永田町への道』）— 設計資料

政治のことを何も知らない一人の国民が、ボランティア・秘書・地方議員を経て国政へ進み、
最終的に総理大臣を目指す戦略育成ゲーム。
**表の政治（憲法・法律・制度）**と**裏の政治（根回し・派閥・カネ・不文律）**の両方を体験し、
清廉な政治家にも、裏金にまみれた政治家にもなれる。

このフォルダは、ゲームを作る前の**ルールの理解**と**ゲームへの落とし込み**をまとめた設計資料です。
同じリポジトリにある旅行アプリ（JapanQuest）とは独立しています。

## 戦略モード「天下取り」（メイン）

`prototype/index.html` が戦略モード。47都道府県の地図の上で派閥を育て、総裁選を勝ち、総理大臣として総選挙に勝つ。
信長の野望のような「地図＋勢力＋人物＋毎月のコマンド」の形。ビルド不要で、ブラウザで開けば動く。

| ファイル | 内容 |
|---|---|
| `tenka-data.js` | 都道府県、政党と派閥、プレイヤーのタイプ、企業、公共事業、役職、コマンドの解説（表と裏）、出来事 |
| `tenka-world.js` | 8つの争点、6つの団体、6つの官庁、4つのメディア、名前のある人物30人、秘書の性格、3つのシナリオ、総理の危機、教科書の評価文 |
| `tenka-engine.js` | ゲームのルール本体。画面に依存せず、Node でも動く。乱数の状態をセーブに持つので同じ種なら同じ展開になる |
| `tenka-election.js` | 選挙戦、開票、惜敗率、連立、参議院、総裁選の多数派工作と投票 |
| `tenka-fx.js` | 似顔絵（表情つき）、効果音とBGM、号外、地元の街の絵、地図のアイコン |
| `tenka-ui.js` | 画面。開始画面、地図、県・人物・情勢・手帳のタブ、各種の画面、開票速報 |
| `tests/sim.mjs` | バランス確認。`node tests/sim.mjs 3 120 p clean` のように、回数・月数・勢力・遊び方を指定して自動で遊ばせる |

### 遊び方の流れ
1. **始め方を選ぶ**：時代（現代／政界再編の嵐／政権交代の風）、勢力（新人の勉強会、与党3派閥の領袖、野党2党の代表）、名前と性別、タイプ、地元、難易度。物語モードの結末も引き継げる。
2. **毎月**：行動力を使って、地域（遊説・後援会・公共事業・擁立）、資金（企業回り・パーティー・銀行）、政策（公約・法案・追及）、党内（餅代・勉強会・同盟・秘書・新党・解散）、人物（会食・貸し借り）、謀略（身辺調査・リーク・裏金）のコマンドを選ぶ。秘書の早瀬がおすすめを示し、「3か月」で自動でも進められる。
3. **月末**：法案が国会の段階を進み、ライバル派閥が動き（引き抜き、リーク、反主流連合、法案潰し）、団体・官庁・メディアとの関係が変わり、出来事（災害、談合の申し出、パーティー券のノルマ、オフレコ懇談、天下りの頼み、炎上、要望書、秘書の暴走）が起きる。
4. **選挙戦**：解散されると3つの日程で、情勢（優勢・接戦・劣勢）を見ながら県ごとに自分・資金・党首・団体を配分する。投票日はテレビの開票速報で、地図が1区ずつ塗り替わる。惜敗率で比例復活もある。
5. **総裁選**：仲間20人で立候補。告示前夜の多数派工作（ポストの約束、貸しの回収、実弾）のあと、議員票＋党員票、決選投票。
6. **総理**：組閣（派閥均衡／論功行賞／適材適所／身内固め、身体検査）、4月の予算配分、危機（感染症、金融危機、隣国との緊張、大地震、閣僚の疑惑）、解散のタイミング。総選挙に勝って2年保てば勝利。
7. **終幕**：後世の教科書の評価文と、清廉・実行力・民意の3つの点数、政治人生で触れた法律の一覧。

### 仕組みの要点
- **貸し借り台帳**：30人の人物それぞれに関係・貸し・借り・記憶がある。貸しは総裁選の票、法案の日程、記事の差し止め、予算枠、融資枠などに使える。
- **考えるライバル**：派閥の領袖は性格（重鎮・策士・人気者・実務）を持ち、あなたの勢力が脅威になると敵対し、次の動きを計画する。身辺調査で計画が見える。
- **争点と一貫性**：8つの争点への立場で、団体の支援と地域の票が変わる。立場を反対に変えると一貫性が下がる。
- **参議院とねじれ**：3年ごとの参院選で与党が過半数を失うと法案が通らなくなる。衆院の3分の2で再可決できる。
- **新党と連立**：仲間4人以上で離党して新党を作れば政党交付金が出る。過半数のない選挙のあとは連立交渉がある。
- **秘書**：性格のある秘書を雇う。「やり手」は勝手に違反をし、冷遇した元秘書は告発する。
- **発覚リスク**：裏の行動で溜まり、週刊誌の報道で表に出る。75を超えると逮捕される。記者に貸しがあれば記事を止められる。
- **セーブ**：自動保存のほか3つの枠と、別の端末へ持ち運べるセーブコード。

## 物語モード（序章〜第4章）

`prototype/monogatari.html` は、政治のルールを物語で学ぶモード（以下の試作版）。

`prototype/` にブラウザで遊べる試作版がある。スマホでもPCでもそのまま動く。
物語の場面で選択肢を選ぶ「テキストアドベンチャー」と、限られた行動で数値を育てる「シミュレーション」が交互に進む
（詳しくは [ゲームデザイン案](docs/10_game_design.md) の「基本の遊び方」）。

- `prototype/monogatari.html` — 画面とゲームの進行。ビルド不要で、ブラウザで開けば動く。
- `prototype/story.js` — ゲームの中身すべて。物語の場面、毎月の行動の一覧、月末の出来事、選挙の計算式の重み、
  表と裏の解説、根拠条文、手帳の用語。法改正や調整はこのファイルだけ直せばよい。

## 前提と注意

- 制度・数値は **2026年時点で把握している内容**に基づく。法改正が頻繁な分野（特に政治資金）なので、
  実装前に [e-Gov法令検索](https://laws.e-gov.go.jp/) や総務省・衆参両院のサイトで最新条文を確認すること。
  不確かな箇所には「※要確認」と付けている。
- ゲームに登場する政治家・政党・団体は**すべて架空**にする。実在の事件は「構造」だけを借り、
  人物は特定できないように作る（名誉毀損リスクの回避と、特定政党への偏りを避けるため）。
- 違法行為はゲーム上の抽象的な選択肢として扱い、現実で再現できる手口の解説にはしない。
  必ず「バレるリスク」と「結末」をセットで描く。
